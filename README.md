# 网易云音乐盒（无名杀扩展）

> 本扩展基于 **[无名杀 · libnoname/noname](https://github.com/libnoname/noname)** 开发，遵循 GPLv3 协议。

在无名杀里听网易云音乐：打开 **音乐盒** 即可调用系统浏览器登录网易云账号，也可以扫码登录；登录后可以选择自己的歌单、推荐歌单、排行榜或直接粘贴歌单链接，随时点歌播放；播放时会自动暂停游戏背景音乐，对局中也能用小窗控制。

> **游戏内「重新开始 / 重来」不会打断音乐。** 音频输出放在一个独立的隐藏窗口里，无名杀重载页面时它不受影响，重载完成后音乐盒会自动重新接管界面（小窗、歌单、进度都还在）。

> **打开游戏自动续播。** 默认开启「开机续播」：每次打开游戏都会自动接着上次的歌曲和进度继续播放。
> **右下角悬浮小窗可拖动**，无操作几秒后会自动收成一张圆形唱片，点一下唱片就展开。

- 版本：1.4.1
- 目录：`<游戏目录>/resources/app/extension/网易云音乐盒/`
- 依赖：无（weapi 加密、二维码生成均为扩展内自带的纯 JS 实现）

## 一、安装

### 方式 A：自动导入（推荐）

1. 把整个 `网易云音乐盒` 文件夹放进无名杀的扩展目录 `<游戏目录>/resources/app/extension/` 下；
2. 打开游戏 → `选项` → `通用` → 开启 **自动导入扩展**；
3. 重启游戏，进入 `扩展` 菜单，列表里会出现 **网易云音乐盒**，点进去把 **开启** 打开；
4. 再次重启游戏，扩展正式生效。

### 方式 B：导入压缩包

1. 到 [Releases](https://github.com/shibaiderman096/noname-netease-musicbox/releases/latest) 下载 `noname-netease-musicbox-v1.4.1.zip`；
2. 打开游戏 → `扩展` 菜单 → **导入扩展** → 选择该 zip；
3. 提示导入成功后游戏会自动重启，扩展同时被启用。

### 方式 C：安卓客户端

1. 手机上直接下载（或从电脑传过去）`noname-netease-musicbox-v1.4.1.zip`；
2. 在安卓客户端里用 **导入扩展** 选择该 zip —— 客户端会提示「扩展已导入成功，是否重启游戏」，确认即可；
   也可以把 `网易云音乐盒` 文件夹整个拷贝到客户端的扩展目录里（不同客户端路径略有差异，通常是 `Android/data/<客户端包名>/files/extension/`）。
3. 重启后进入 `扩展` 菜单，把 **网易云音乐盒 → 开启** 打开。

> 安卓端不需要任何额外配置：扩展会自动识别客户端的原生网络通道（见「九、安卓端说明」）。

> 提示：扩展页面的选项保存在 `lib.config` 里（键名前缀 `extension_网易云音乐盒_`），删除扩展目录即可完全清理。

## 二、登录网易云账号

扩展页面只留一个 **音乐盒** 入口，登录相关操作都在面板左侧的 **账号与登录** 里：

| 方式 | 入口（音乐盒 → 账号与登录） | 说明 |
| --- | --- | --- |
| 扫码登录（推荐） | **生成登录二维码** | 游戏内直接显示二维码，用手机「网易云音乐」App 扫码确认 |
| 浏览器登录 | **打开浏览器登录网易云** | 调用**系统默认浏览器**打开 <https://music.163.com/#/login>，登录完成后把 Cookie 粘到同页的「手动粘贴 Cookie」即可 |
| 弹出登录窗口 | **弹出登录窗口并自动同步** | 在独立窗口中登录，扩展会自动读取该窗口的 Cookies，无需手动复制 |
| 手动 Cookie | **手动粘贴 Cookie** | 直接粘贴 `MUSIC_U=...` 或整条 Cookie |

**怎么复制 Cookie：** 在浏览器登录 <https://music.163.com> 后按 `F12` → `Application / 应用` → `Cookies` → `https://music.163.com` → 找到 `MUSIC_U`，复制它的值（或整行 `MUSIC_U=...`），粘贴到「手动粘贴 Cookie」的输入框后点 **保存并验证**。

未登录也能用：推荐歌单、排行榜、搜索、歌单链接都可以浏览，免费歌曲可以直接播放；VIP 歌曲在未登录时只能试听 45 秒。

## 三、选歌与播放

扩展页面点 **音乐盒**（或对局中点击右上角 **音乐** 按钮）打开播放面板：

- 左侧分类：
  - **我的歌单**：登录后读取你创建/收藏的歌单；
  - **推荐歌单**：网易云个性化推荐；
  - **排行榜**：飙升榜、新歌榜、原创榜、热歌榜等；
  - **搜索歌曲**：可切换"单曲 / 歌单"；
  - **歌单 ID / 链接**：粘贴 `https://music.163.com/#/playlist?id=3778678` 或直接输入 ID；
  - **常用歌单**：自己收藏的常用歌单（在歌单页点工具栏的 `☆ 常用`）。
- 点击任意歌曲立即播放；歌单右上角的 `▶ 播放` 可以整单播放，`播放全部` / `随机播放` 同理。
- 底部控制条：上一首、播放/暂停、下一首、**歌词**、播放模式（顺序 / 列表循环 / 单曲循环 / 随机）、进度条、音量。
- **歌词**：点底部 `词` 按钮把列表区域切换成歌词视图，当前唱到的那句会高亮并自动滚动居中；**点某一行可以跳到那一句**；再点一次 `词` 回到列表。歌词按曲目缓存，来回切换不会再请求接口。
- 点击 `—` 收起为右下角小窗，对局中也能随时切换歌曲；**拖动标题栏**可以把面板挪到任意位置（位置会被记住，手机端用触摸拖动同样有效）。
- **右下角悬浮小窗**：
  - 可以把小窗**拖到任意位置**（条形和唱片共用同一个位置，会被记住，重开游戏也不变），**鼠标与手机触摸都支持**；
  - 小窗上点 `📀` 立即收成圆形唱片；也可以什么都不做，**几秒无操作后自动收起**；
  - 收起后的**圆形唱片**会显示当前专辑封面，播放时缓慢旋转，**点一下即可展开**回完整小窗，**并且可以拖动换位置**（刚拖完的 0.3 秒内点击会被忽略，避免手一松就误触）；
  - 面板打开时不会重复显示小窗，关掉面板它就会回来。
- **打开游戏自动续播**：默认开启，进入游戏后自动接着上次的歌曲与播放进度继续播（可在扩展页面「开机续播」里关闭）。
- **游戏内「重新开始 / 重来」不影响播放**：无名杀会重载整个页面，而音乐在一个独立的隐藏音频窗口里继续播放；重载完成后音乐盒会自动恢复右下角小窗、当前歌曲与整个歌单列表，直接接着用就行。
- 「歌单 → 播放」的记录会保存在本机（`localStorage`），即使完整重启游戏，下次打开音乐盒或点播放也会沿用上一次的歌单。

## 五、常见问题

**1. 歌曲只能播放 45 秒？**
这是网易云的版权限制：VIP 歌曲在未登录（或非会员）时只返回 45 秒试听片段。登录会员账号后可完整播放。

**2. 提示"音频加载失败"？**
该歌曲可能已下架、需要付费专辑，或播放直链过期（直链有效期约 20 分钟，扩展会自动缓存 30 分钟；重新点一次即可换新链接）。遇到失败会自动跳到下一首。

**3. 浏览器登录了，但音乐盒里还是未登录？**
浏览器和游戏是两个独立的 Cookie 空间。请在音乐盒 → **账号与登录** → 「手动粘贴 Cookie」里粘贴 `MUSIC_U`，或者直接用 **扫码登录** / **弹出登录窗口** 自动同步。

**4. 面板挡住了游戏界面？**
点击标题栏的 `—` 收起为小窗，或直接关闭面板；关闭后音乐继续播放。

**5. 重新开始游戏后音乐还在放，界面呢？**
音乐盒会自动恢复右下角小窗和当前歌单（约 1 秒内），点小窗上的 🔍 就能展开完整面板。若没有自动出现，重新点一次扩展页面的「音乐盒」即可，播放本身不会中断。

**6. 后台是不是多了一个窗口/进程？**
音乐盒会在后台开一个不可见的音频窗口（标题为 `NMB-AUDIO-SINK`）来保证重载不断歌，它挂在游戏窗口下，**关闭游戏时会自动一起结束**，不占额外操作。

**7. 想彻底卸载？**
删除 `resources/app/extension/网易云音乐盒/` 目录，并在 `扩展` 菜单里删除该扩展即可（`lib.config` 里的相关键会自动清理）。

**8. 关闭游戏后音乐还在响？**
正常不会。音频窗口每秒检查一次"游戏窗口是否还在"，游戏一关它就立刻销毁自己；另外它还挂在游戏窗口下、并有 45 秒心跳兜底。若仍遇到，说明该窗口未能读取窗口列表（例如运行环境阉割了 `@electron/remote`），可以在任务管理器里结束 `noname.exe`，并反馈给我。

**9. 每次打开游戏自动放歌，怎么关？**
扩展页面把 **开机续播** 关掉即可。播放记录存在本机 `localStorage`（键名 `nmb_playback_state_v1`），清掉它就不会再续播。

**10. 右下角小窗不见了 / 变成一张圆盘？**
小窗无操作几秒会主动收成圆盘（防止挡住对局）；点一下圆盘就展开，扩展页面把 **小窗自动收起** 改成 0 可以让它一直保持完整小窗。另外面板打开时小窗会暂时隐藏。

**11. 安卓端提示「Failed to fetch」/ 一直转圈？**
见下方「九、安卓端说明」——v1.3.0 起已内置安卓原生网络通道，直接用新版即可；如果你是从旧版升级，请重新导入一次 zip 并重启。

## 九、安卓端说明

安卓客户端是 Cordova/WebView 环境，而 `music.163.com` **不返回 CORS 头**，所以 WebView 里直接用 `fetch` 一定会失败（就是你看到的 `Failed to fetch`）。v1.3.0 起扩展内置了四套网络后端，会自动挑选可用的那一套：

| 后端 | 使用场景 | 特点 |
| --- | --- | --- |
| `node` | 桌面端（Electron） | 不受 CORS 限制，能读 `Set-Cookie`（扫码登录靠它） |
| `capacitor-http` | Capacitor 壳客户端（由理/cola 等，页面里有 `CapacitorHttpAndroidInterface`） | 用 `CapacitorHttp` 原生请求，绕开跨域，能读响应头 |
| `cordova-http` | 安卓客户端装了 `cordova-plugin-advanced-http` | 原生请求，可自定义任意请求头，能读响应头 |
| `file-transfer` | 安卓客户端（`cordova-plugin-file-transfer`） | POST 走原生「上传」、GET 走原生「下载」，同样绕开 CORS |
| `fetch` | 网页版兜底 | 会被跨域拦下（music.163.com 没有 CORS 头） |

配套做的四件事：
1. **参数改放查询串**：网易云不接受 GET 传参，但接受把 `params`/`encSecKey` 放在 URL 上的 POST（实测 multipart / urlencoded / 文本 / 空 body 全部返回 200），这样安卓的原生上传通道也能调接口；
2. **播放直链统一升级为 https**：安卓上 https 页面加载 http 音频会被拦，实测同一地址换 https 一样可播（206 + audio/mpeg）；
3. **外部浏览器改用 InAppBrowser**：安卓端「打开浏览器登录」会调起系统浏览器（`cordova.InAppBrowser.open(url, "_system")`）；
4. **拖动全部改用 Pointer Events**：手机端只有触摸事件，原来只监听 `mousedown` 所以拖不动；现在面板标题栏、悬浮小窗、圆形唱片都用 pointer 事件（并对可拖动元素设了 `touch-action: none`，避免拖动变成滚页面）。

在音乐盒 → **账号与登录** 的顶部能看到当前实际使用的网络通道，那里还有 **网络诊断**（一键输出设备环境与四条链路的实测结果）和 **手动指定通道**（自动 / Capacitor / 文件传输 / 原生HTTP / fetch）。

安卓端的已知限制：
- 如果客户端只有 `file-transfer`（读不到响应头），**扫码登录无法自动同步登录状态**——界面会提示你改用「浏览器登录 + 手动粘贴 Cookie」；
- 如果客户端没有任何原生网络能力（只有 `fetch`），会被跨域拦下，此时需要换用其它客户端或客户端版本；
- 「弹出登录窗口自动同步」「重新开始不断歌」「关闭游戏自动退出音频窗口」这些依赖 Electron 的能力在安卓上不可用（会自动跳过，不影响播放）。

## 十、自动发版（GitHub Actions）

仓库里带了 `.github/workflows/release.yml`：**打 tag 就会自动打包 zip 并挂到 Release 上**，不需要本地 git push，也不需要手工上传附件。

发新版本的步骤：

1. 改好代码，把 `extension.js` 的 `VERSION`、`info.json` 的 `version`、README 里的版本号改一致；
2. 在 GitHub 网页上 **Releases → Draft a new release**，新建 tag（例如 `v1.4.0`）并发布（或者到 **Actions → Release → Run workflow** 手动填版本号）；
3. 工作流会：校验 `info.json` / `extension.js` 的版本与 tag 一致 → 打包 `noname-netease-musicbox-v1.4.1.zip`（排除 `.github`、`dist` 等）→ 校验压缩包内文件齐全 → 创建/更新 Release 并附上 zip。

版本号不一致时工作流会直接失败并提示，避免发出版本对不上的包。

## 十一、说明

本扩展只调用网易云音乐官方公开接口（`music.163.com/weapi`），不上传任何数据；登录状态（Cookie）只保存在你本机的无名杀配置里。

本扩展基于 [无名杀（libnoname/noname）](https://github.com/libnoname/noname) 开发，与网易云音乐官方无关，仅供个人学习与自用。
