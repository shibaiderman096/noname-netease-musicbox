# 网易云音乐盒（无名杀扩展）

> 本扩展基于 **[无名杀 · libnoname/noname](https://github.com/libnoname/noname)** 开发，遵循 GPLv3 协议。

在无名杀里听网易云音乐：**扩展页面一键调用系统浏览器登录网易云账号**，也可以扫码登录；登录后可以选择自己的歌单、推荐歌单、排行榜或直接粘贴歌单链接，随时点歌播放；播放时会自动暂停游戏背景音乐，对局中也能用小窗控制。

> **游戏内「重新开始 / 重来」不会打断音乐。** 音频输出放在一个独立的隐藏窗口里，无名杀重载页面时它不受影响，重载完成后音乐盒会自动重新接管界面（小窗、歌单、进度都还在）。

- 版本：1.0.2
- 目录：`<游戏目录>/resources/app/extension/网易云音乐盒/`
- 依赖：无（weapi 加密、二维码生成均为扩展内自带的纯 JS 实现）

---

## 一、安装

### 方式 A：自动导入（推荐）

1. 把整个 `网易云音乐盒` 文件夹放进无名杀的扩展目录 `<游戏目录>/resources/app/extension/` 下；
2. 打开游戏 → `选项` → `通用` → 开启 **自动导入扩展**；
3. 重启游戏，进入 `扩展` 菜单，列表里会出现 **网易云音乐盒**，点进去把 **开启** 打开；
4. 再次重启游戏，扩展正式生效。

### 方式 B：导入压缩包

1. 到 [Releases](https://github.com/shibaiderman096/noname-netease-musicbox/releases/latest) 下载 `noname-netease-musicbox-v1.0.2.zip`；
2. 打开游戏 → `扩展` 菜单 → **导入扩展** → 选择该 zip；
3. 提示导入成功后游戏会自动重启，扩展同时被启用。

> 提示：扩展页面的选项保存在 `lib.config` 里（键名前缀 `extension_网易云音乐盒_`），删除扩展目录即可完全清理。

## 二、登录网易云账号

打开 `扩展` → `网易云音乐盒`，扩展页面提供多种登录方式：

| 方式 | 扩展页面按钮 | 说明 |
| --- | --- | --- |
| 浏览器登录 | **浏览器登录** | 点击后调用**系统默认浏览器**打开 <https://music.163.com/#/login>，登录完成后把浏览器 Cookie 粘贴到 **会话** 项即可同步账号 |
| 扫码登录 | **扫码登录** | 游戏内直接显示二维码，用手机「网易云音乐」App 扫码确认，最省事，**推荐** |
| 弹出登录窗口 | 音乐盒 → 账号与登录 → **弹出登录窗口并自动同步** | 在独立窗口中登录，扩展会自动读取该窗口的 Cookies，无需手动复制 |
| 手动 Cookie | **会话**（扩展页面输入框） | 直接粘贴 `MUSIC_U=...` 或整条 Cookie |

**怎么复制 Cookie：** 在浏览器登录 <https://music.163.com> 后按 `F12` → `Application / 应用` → `Cookies` → `https://music.163.com` → 找到 `MUSIC_U`，复制它的值（或整行 `MUSIC_U=...`），粘贴到扩展页面的 **会话** 输入框后按回车/点击别处即可保存。

未登录也能用：推荐歌单、排行榜、搜索、歌单链接都可以浏览，免费歌曲可以直接播放；VIP 歌曲在未登录时只能试听 45 秒。

## 三、选歌与播放

扩展页面点 **音乐盒**（或对局中点击右上角 **音乐** 按钮）打开播放面板：

- 左侧分类：
  - **我的歌单**：登录后读取你创建/收藏的歌单；
  - **推荐歌单**：网易云个性化推荐；
  - **排行榜**：飙升榜、新歌榜、原创榜、热歌榜等；
  - **搜索歌曲**：可切换"单曲 / 歌单"；
  - **歌单 ID / 链接**：粘贴 `https://music.163.com/#/playlist?id=3778678` 或直接输入 ID；
  - **常用歌单**：自己收藏的常用歌单（在歌单页点工具栏的 `☆ 常用`）。
- 点击任意歌曲立即播放；歌单右上角的 `▶ 播放` 可以整单播放，`播放全部` / `随机播放` 同理。
- 底部控制条：上一首、播放/暂停、下一首、播放模式（顺序 / 列表循环 / 单曲循环 / 随机）、进度条、音量。
- 点击 `—` 收起为右下角小窗，对局中也能随时切换歌曲；拖动标题栏可以把面板挪到任意位置（位置会被记住）。
- **游戏内「重新开始 / 重来」不影响播放**：无名杀会重载整个页面，而音乐在一个独立的隐藏音频窗口里继续播放；重载完成后音乐盒会自动恢复右下角小窗、当前歌曲与整个歌单列表，直接接着用就行。
- 「歌单 → 播放」的记录会保存在本机（`localStorage`），即使完整重启游戏，下次打开音乐盒或点播放也会沿用上一次的歌单。

## 四、扩展页面选项说明

| 选项 | 作用 |
| --- | --- |

| 音量 | 0 ~ 100 |
| 使用说明 | 简要帮助 |

## 五、常见问题

**1. 歌曲只能播放 45 秒？**
这是网易云的版权限制：VIP 歌曲在未登录（或非会员）时只返回 45 秒试听片段。登录会员账号后可完整播放。

**2. 提示"音频加载失败"？**
该歌曲可能已下架、需要付费专辑，或播放直链过期（直链有效期约 20 分钟，扩展会自动缓存 30 分钟；重新点一次即可换新链接）。遇到失败会自动跳到下一首。

**3. 浏览器登录了，但音乐盒里还是未登录？**
浏览器和游戏是两个独立的 Cookie 空间。请在扩展页面的 **会话** 里粘贴 `MUSIC_U`，或者使用 **扫码登录** / **弹出登录窗口** 自动同步。

**4. 面板挡住了游戏界面？**
点击标题栏的 `—` 收起为小窗，或直接关闭面板；关闭后音乐继续播放。

**5. 重新开始游戏后音乐还在放，界面呢？**
音乐盒会自动恢复右下角小窗和当前歌单（约 1 秒内），点小窗上的 🔍 就能展开完整面板。若没有自动出现，重新点一次扩展页面的「音乐盒」即可，播放本身不会中断。

**6. 后台是不是多了一个窗口/进程？**
音乐盒会在后台开一个不可见的音频窗口（标题为 `NMB-AUDIO-SINK`）来保证重载不断歌，它挂在游戏窗口下，**关闭游戏时会自动一起结束**，不占额外操作。

**7. 想彻底卸载？**
删除 `resources/app/extension/网易云音乐盒/` 目录，并在 `扩展` 菜单里删除该扩展即可（`lib.config` 里的相关键会自动清理）。

**8. 关闭游戏后音乐还在响？**
正常不会。音频窗口每秒检查一次"游戏窗口是否还在"，游戏一关它就立刻销毁自己；另外它还挂在游戏窗口下、并有 45 秒心跳兜底。若仍遇到，说明该窗口未能读取窗口列表（例如运行环境阉割了 `@electron/remote`），可以在任务管理器里结束 `noname.exe`，并反馈给我。

## 七、目录结构

```
网易云音乐盒/
├── extension.js        扩展入口：扩展页面选项、对局内按钮、自动显示与状态恢复
├── info.json           扩展信息（名称/作者/简介/版本）
├── player.html         音频输出窗口页面（独立窗口，重载不断歌）
├── README.md
└── src/
    ├── ui.js           播放面板与登录界面（DOM + 交互）
    ├── player.js       播放内核（歌单、模式、音质、双输出后端、跨重载状态恢复）
    ├── audio-sink.js   音频输出窗口的逻辑（只负责播放给定 URL）
    ├── api.js          网易云接口封装（账号/歌单/搜索/播放地址/扫码）
    ├── crypto.js       weapi 加密（AES-128-CBC + RSA，纯 JS）
    ├── net.js          网络请求（Node https 优先，fetch 兜底）
    ├── qrcode.js       二维码生成（纯 JS，字节模式 版本1~10 纠错L/M）
    ├── store.js        配置与会话持久化（lib.config）
    ├── style.js        面板样式（nmb- 前缀，避免与游戏样式冲突）
    └── util.js         工具函数（打开外部浏览器、时间格式化、事件触发器）
```

## 八、说明

本扩展只调用网易云音乐官方公开接口（`music.163.com/weapi`），不上传任何数据；登录状态（Cookie）只保存在你本机的无名杀配置里。

本扩展基于 [无名杀（libnoname/noname）](https://github.com/libnoname/noname) 开发，与网易云音乐官方无关，仅供个人学习与自用。
